# Материалы для Яндекс Игр

Пакет для черновика в Консоли — по образцу «Городков». Всё, что загружается, лежит в `upload/`.

| Поле черновика | Файлы | Размер |
|---|---|---|
| Иконка | `upload/icon_512.png` | 512×512 |
| Maskable иконка | `upload/icon_maskable_512.png` | 512×512, всё важное в центральном круге |
| Обложка (ru / en) | `upload/cover_ru.png`, `upload/cover_en.png` | 800×470 |
| Скриншоты, десктоп (ru / en) | `upload/screen_{ru,en}_{1..7}_*.png` | 1920×1080 |
| Скриншоты, мобильные (ru / en) | `upload/mobile_{ru,en}_{1..7}_*.png` | 1080×1920 |
| Горизонтальное видео (ru / en) | `upload/video_{ru,en}_landscape.mp4` | 1920×1080, 26 с, H.264 |
| Вертикальное видео (ru / en) | `upload/video_{ru,en}_portrait.mp4` | 1080×1920, 26 с, H.264 |
| Название, описания, «Как играть» | `texts.md` | с подсчётом символов под лимиты |

Архив игры собирается отдельно: `npm run build:yandex` → `yui-yandex.zip` в корне проекта.

## Как пересобрать

```bash
python scripts/promo-yandex.py      # иконки, обложки, значки сайта (из art/raw)
npm run dev                         # в отдельном окне
node scripts/store-shots.mjs        # скриншоты и видео (Playwright)
```

Скриншоты снимаются с постановочных сцен (`src/dev/shots.tsx`, только на dev-сервере:
`?shot=<сцена>&lang=ru|en`) — это настоящий интерфейс игры в выгодной позиции.
Видео — запись настоящей партии против трёх ботов.

Скриншоты и видео в git не хранятся (110 МБ, воспроизводятся командой выше).

## Иконка

Варианты сгенерированы в Codex (`art/raw/icon_a_ten.png`, `icon_b_ace.png`, `icon_c_fire.png`),
сравнение в большом и маленьком размере — `icons/compare.png`. Выбран `icon_c_fire`:
один крупный предмет с драматичным светом, как у «Городков», и стартовая карта игры.
Другой вариант — поменять `ICON_SOURCE` в `scripts/promo-yandex.py` и пересобрать.
