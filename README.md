# YUI

Карточная игра в браузере: 20 карт от десятки до туза, без мастей и козырей.
Правила — вариант польской игры «Пан»: вместо 9 червей стартовая карта — 10 пик.

Играть: https://arybashov.github.io/yui/

## Что есть

- игра с ботами (1–4 соперника, два уровня);
- онлайн с друзьями по коду комнаты — напрямую между браузерами (PeerJS);
- обучение из 7 шагов и текстовые правила;
- счёт буквами: проигравший раздачу получает Y, U, I; собравший YUI проигрывает матч;
- звуки, синтезированные в браузере.

## Запуск на своём компьютере

Нужен Node.js 22 или новее.

```bash
npm install
npm run dev
```

Игра откроется на http://localhost:5173. На Windows можно просто запустить `start.bat`.

```bash
npm test        # тесты правил
npm run build   # сборка в dist/
```

## Устройство

| Папка | Что внутри |
|---|---|
| `src/game` | правила (`engine.ts`), боты (`bot.ts`), ведение партии (`session.ts`) |
| `src/net` | сетевая игра: комната хоста и клиент гостя |
| `src/tutorial` | шаги обучения |
| `src/ui` | интерфейс на React, звуки |
| `art` | исходные листы карт, тексты запросов и скрипт нарезки |
| `public` | готовые картинки карт и стола |

## Арт

Карты, рубашка и стол сгенерированы в Codex. Листы лежат в `art/raw`, запросы — в `art/prompts`.
Скрипт `python art/slice.py` вырезает карты с зелёного фона и кладёт их в `public/cards`
(нужны Pillow и NumPy).
